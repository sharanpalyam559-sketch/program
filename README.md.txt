# FacultyPulse - Anonymous Faculty Feedback System

FacultyPulse is a modern, responsive web application designed for educational institutions to collect fully anonymous student feedback for faculty members across key performance indicators.

## Features

### 👨‍🎓 Student Portal
- **Subject & Faculty View:** Access assigned classes and teaching faculty.
- **Anonymous Rating System:** Evaluate faculty on 5 parameters:
  - Clarity of Teaching
  - Punctuality
  - Subject Knowledge
  - Communication Skills
  - Student Support
- **Duplicate Prevention:** Single submission rule enforced per subject per student.
- **Constructive Feedback:** Optional open text field for specific comments.

### 👨‍💼 Admin Dashboard
- **Analytics & Trends:** Real-time visual metrics, overall score breakdown, and total response counts.
- **Faculty & Subject Mapping:** Select and inspect faculty performance per subject/class.
- **Comment Feed:** View aggregated student text feedback safely detached from student identifiers.
- **Data Export:** Export detailed evaluation reports.

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
1. Extract the project source:
```bash
unzip FacultyPulse.zip
cd FacultyPulse
```

2. Install dependencies:
```bash
npm install
```

3. Run development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```
